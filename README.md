# Tipz.co Coming Soon Landing Page — v2.0

This rebuild applies the approved Tipz.co **Refinement C** identity.

## Brand implementation
- Approved Tip / Diamond mark
- Purple `#6C00FF`
- Orange `#FF6A00`
- Deep Neutral `#0F0B2D`
- White `#FFFFFF`
- Inter/system sans-serif typography
- One-color Tipz.co lettering with orange period

## Page intent
A premium, deliberately minimal one-screen coming-soon page. It is designed to intrigue without over-explaining Tipz.co and to work without vertical scrolling on common desktop, tablet, and mobile viewports.

## Deployment
This package is static and has no runtime dependencies. Upload the folder contents to the web root. Before launch, verify HTTPS and the canonical root/www routing.
